# 📚 圖書館座位預約 Web 系統 (Library Seat Reservation Web System)

專為圖書館設計的現代化、輕量級座位預約 Web 網站系統。使用者無需登入，即可直接在瀏覽器中進行劃位、調整預約時段並即時查看 10 個座位的預約狀況。

---

## 🌟 核心規範與系統特色

1. **10 個正方形座位展示**：
   - 介面以 10 個正方形座位卡片（2 列 5 欄）排列，直觀清晰。
2. **直覺顏色切換**：
   - 🟢 **綠色 (可預約)**：該時段無人使用，標示「🟢 可預約」，點擊即可劃位。
   - 🟡 **黃色 (已被預約)**：該時段已被佔用，標示「🟡 【已被預約】」，並即時顯示登記學號與時段。
3. **免登入 & 學號登記**：
   - 使用者不需要帳號密碼登入，直接於上方輸入學號即可完成登記。
4. **預約時段彈性調整與嚴格限制**：
   - 📅 **限定今日與隔日**：
     - **今日**：只能預約目前時間所剩餘的時段（過期時段自動過濾防呆）。
     - **隔日**：開放全天開放時段（08:00 ~ 22:00）。
     - 超出隔日的日期不開放預約。
   - ⏳ **單次上限 3 小時**：
     - 提供 1 小時、2 小時、3 小時（上限）選項；若需延長使用，需於結束後重新預約。
   - 🛡️ **時段重疊衝突檢查**：
     - 系統自動判定時間重疊，防止同一座位在同一時段被重複預約。
5. **退位與資料自動保存**：
   - 點擊已被預約的黃色座位，可查看詳情並一鍵退位（立即轉回綠色）。
   - 預約資料自動儲存於 `reservations.json`，伺服器重啟依然完整保留。

## 🚀 啟動方式

### 方法一：Windows 一鍵啟動 (最推薦)
直接在資料夾中雙擊執行 **[`start_web.bat`](file:///C:/Users/MCU/.gemini/antigravity/scratch/library_reservation/start_web.bat)**。
系統會自動在瀏覽器中開啟 `http://localhost:8080`。

### 方法二：終端機啟動
在專案目錄下執行：
```powershell
py server.py
```
或
```powershell
python server.py
```
接著在瀏覽器打開：`http://localhost:8080`

## 📖 操作流程

1. **登記學號**：在「✍️ 登記學號」欄位輸入您的學號（例如：`B11209001`）。
2. **選擇日期與時間**：
   - 點選【今日】或【隔日】。
   - 下拉選擇【開始時間】（今日僅顯示剩餘時段）。
   - 點選【預約時長】（可選 1 小時、2 小時、最多 3 小時）。
3. **選擇座位預約**：
   - 查看 10 個座位，點擊任一【綠色座位】。
   - 彈出確認視窗核對學號與時段，點擊「確認預約劃位」。
   - 座位即時轉為【黃色】並顯示已被預約。
4. **釋出座位 (退位)**：
   - 點擊該【黃色座位】，在彈出視窗中點選「釋出此座位 (退位)」即可。
